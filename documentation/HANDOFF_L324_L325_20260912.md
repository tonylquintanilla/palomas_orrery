## LESSONS WORTH CARRYING

- **A rule in a skill can be overlooked; a guard in the run cannot --
  and making it mechanical forces a precision the rule would have got
  wrong.** "One assignment per line" was about to be written into a
  skill. Building it as a check found four multi-line top-level
  assignments already in the store, all of them container literals a
  lookup table cannot avoid. The sentence would have been false about
  four rows on the day it was written, and nothing would ever have run
  it against the file it described.
- **A check that gates but does not SHOW cannot be told from one that
  never ran.** The row-shape guard was failing the run correctly from
  the moment it shipped. What was missing was evidence on a pass, in
  the place Tony actually reads. Visibility is part of the check, not
  decoration on it.
- **The argument for a stored expression was worth less than it
  looked.** An expression recomputes when an input moves; a literal
  does not. True, and beside the point here, because NOTHING TESTED
  EITHER ROW -- and the magnetopause was already a frozen literal
  inheriting a pressure that is declared pending. The failure mode the
  ruling was accused of creating already existed, unguarded.
- **A silent recompute changes a published number with nobody looking.**
  A literal plus a test fails loudly instead. That is the better half of
  the trade, and it is the same shape as everything else this session.
- **Do not restate a retired figure while retiring it.** The first draft
  of the item 6a patch explained the magnetotail retirement by quoting
  what the line used to say, leaving the retired number in a served
  field. Caught before delivery. A figure in prose is what L-323 is
  about; writing one back in to explain its removal is the failure
  performed on the fix.
- **A label is a claim, and the cheap check caught it.** Two SHAs
  arrived swapped -- the orrery's second push reported as the gallery's.
  One `ls-remote` on each repo settled it, and the real finding was that
  the gallery had never been pushed at all.
- **A run that says "inconclusive" is doing its job.** The first live
  gallery run found three stale files and declined to call itself a
  pass, naming the two possible causes. It was right: unpushed work, not
  deploy lag.
