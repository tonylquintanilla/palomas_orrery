## Method, for the next coordinator

What this session learned, beyond the method section in the handoff
of Nov 16, which still applies.

- READING HIS FOLDER WORKS; A PLACED FILE CANNOT BE READ BACK. Staging
  a file the Code session wrote worked every time. Staging a file this
  session had placed was refused. Give a Code session the fingerprint
  of anything that matters, as the brief did.
- MEASURE A DRAFT BY BUILDING IT. This session estimated the reduced
  protocol twice, "750 to 800" and then 831, and the first build was
  896. Both estimates were given to Tony and both were wrong.
- THE MODEL IS A POOR JUDGE OF ITS OWN RULES. The first draft kept
  coaching that Tony then cut in five comments and eight numbered
  answers. His ruling 4 of Nov 10 said a model's word is not evidence;
  this is the worked case.
- ASK TONY BY NUMBER, WITH THE TEXT IN FRONT OF HIM. He asked for it:
  "Can you excerpt the parts I should read again itemized so I can
  reply likewise?" Twenty-one passages, marked unchanged or new, got
  an answer on each in one message.
- THE COLD READ EARNED ITS COST. Write the expected answers before the
  read. A chat outside the Project, in incognito, found eight faults
  the author and Tony had both read past, two of them contradictions.
- A CODE SESSION'S REPORT IS A CLAIM. All three parts were right. One
  plan stated in a report went past the brief (a fourth skill) and one
  record was a misreading (the door). Both were caught by reading the
  files, not the report.
