## The words

Each keeps JPL's or the IAU's word and adds what it means. No number
appears that the room does not serve.

| Group | The explanation |
|---|---|
| Encke-type comets | Encke-type: a comet whose orbit is smaller than Jupiter's; JPL names the class for Comet Encke. |
| Jupiter-family comets | Jupiter-family: a comet whose orbit is governed by Jupiter's gravity. |
| Halley-type comets | Halley-type: a comet that returns after decades to centuries; JPL names the class for Halley's Comet. |
| Comets | Comet: JPL's class for a comet whose orbit fits none of its named classes. |
| Hyperbolic comets | Hyperbolic: on an open path around the Sun, not a closed loop. |
| Interstellar objects | The I in 1I, 2I and 3I stands for interstellar: the IAU's numbering for objects that came from another star system. |
| Aten asteroids | Aten: a near-Earth asteroid whose orbit is smaller than Earth's but reaches out across it. |
| Apollo asteroids | Apollo: a near-Earth asteroid whose orbit is larger than Earth's and crosses it. |
| Amor asteroids | Amor: a near-Earth asteroid that comes close to Earth's orbit from outside without crossing it. |
| Main asteroid belt | Main belt: asteroids whose orbits lie between Mars and Jupiter. |
| Jupiter Trojans | Jupiter Trojan: an asteroid that shares Jupiter's orbit, in one of two swarms ahead of and behind the planet. |
| Centaurs | Centaur: a small body whose orbit lies between Jupiter's and Neptune's. |
| Trans-Neptunian objects | Trans-Neptunian: a body whose orbit lies beyond Neptune's. |

## The sources

- The thirteen classes: JPL's Small-Body Database filter parameters,
  the table of orbit classes,
  https://ssd-api.jpl.nasa.gov/doc/sbdb_filter.html, read 2026-10-26.
  Its words, which the explanations follow without their numbers: Aten,
  "Near-Earth asteroid orbits similar to that of 2062 Aten (a < 1.0 au;
  Q > 0.983 au)"; Apollo, "Near-Earth asteroid orbits which cross the
  Earth's orbit"; Amor, "(1.017 au < q < 1.3 au)"; Encke-type, "(Tj >
  3; a < aJ)"; Jupiter-family, "as defined by Levison and Duncan (2 < Tj
  < 3)"; Halley-type, "classical definition (20 y < P < 200 y)"; Comet,
  "Comet orbit not matching any defined orbit class"; Hyperbolic,
  "Comets on hyperbolic orbits (e > 1.0)"; Main-belt, "(2.0 au < a <
  3.2 au; q > 1.666 au)"; Jupiter Trojan, "trapped in Jupiter's L4/L5
  Lagrange points"; Centaur, "Objects with orbits between Jupiter and
  Neptune"; TransNeptunian, "Objects with orbits outside Neptune".
- The I: the IAU's announcement ann17045,
  https://iauarchive.eso.org/news/announcements/detail/ann17045/, read
  2026-10-26: "From now on the letter "I" is used to indicate
  "interstellar"."
- Perihelion: JPL's Horizons manual,
  https://ssd.jpl.nasa.gov/horizons/manual.html, read 2026-10-26:
  "QR ........ Perihelion distance (au)".

## Two readings to check

- Jupiter-family: JPL's definition is a value of Tisserand's parameter
  with respect to Jupiter between 2 and 3, which is how astronomers
  measure how strongly Jupiter controls an orbit. "Governed by Jupiter's
  gravity" is that, in plain words.
- Encke-type: the definition also says the comet is only loosely tied
  to Jupiter (Tisserand's parameter above 3). The draft leaves that out
  and says only what a visitor can see, an orbit smaller than Jupiter's.
