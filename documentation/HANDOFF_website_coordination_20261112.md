## What this session learned (method, for the next coordinator)

- THE COPY-BACK CAN SEND AN OLD COPY. Writing a file back to Tony's disk
  (device_commit_files) twice from the same staged file name sent the
  earlier version the second time, at the moment of the write (Nov 12,
  00:09 and 09:15; nothing of Tony's lost). Write each time from a new
  name (`ledger_<date>_<time>.md`), then wait about 40 seconds, stage
  the file again and compare it byte for byte. Right after a write,
  staging may refuse the file as "hardlinked"; wait and stage again. It
  was first blamed on an editor or OneDrive, wrongly, and corrected.
- EDIT THE DISK COPY, NOT YOUR OWN. While a Code session is open in the
  same folder it writes the ledger too. Stage Tony's file, edit that,
  and pass the staged file's time as the write's guard.
