## 4. Four things the manifest did not foresee

1. **The unit checker could not judge the two new kilometre rows.**
   Earth radii times kilometres reads as an area to astropy. The checker
   already converts when a row DIVIDES by a defining constant; it now
   converts when a row MULTIPLIES by one and the other factor is in that
   constant's token. Two fixtures, one passing and one failing (kilometres
   times Earth's radius still reads as an area). Without the rule both new
   rows fail, which is the twelfth line of section 3.
2. **The store's new formulas called numpy, and numpy's numbers broke a
   drawing.** Earth's dipole cone stopped being built at all, with no
   error on screen: a comparison on a numpy number gives a numpy
   true/false, and plotly refuses it. Found by building the real traces,
   not by any checker. The store now calls Python's own maths functions,
   so every value is a plain float, as every value was before this build.
3. **Two more display sites print the standoffs**, in the shell
   configuration table's tooltip text. It has no consumer, and the
   conventions say to keep it in step with its live twin, so it moves
   with the four the manifest names.
4. **The size guard requires one line per value**, so the two standoffs,
   the tilt and its rate are each written on one long line.

## 5. The two red checks, and what they mean

- **Constants change** fails when you run the maintenance run before
  committing. It reads the store's diff against the last commit and
  fails on any line it cannot read. By design it refuses a formula that
  calls a function and a typed number that has become a formula, so it
  names eight lines, all of them changes this patch makes on purpose:
  `DEG_PER_RAD`, the dipole tilt, the tilt rate and the magnetopause
  standoff as lines it cannot read, and the outer belt's peak, the
  dipole tilt and the two standoffs as names the diff dropped that the
  file still assigns. Read its list, check that it names those eight and
  nothing else, and carry on; after the commit it compares against the
  new commit and goes quiet. Recorded for the ledger as a class: the
  change report cannot read a formula with a function call, or a literal
  that became one.
- **Reset completeness** fails only in the sandbox, which has no Windows
  screen colours. It failed the same way before any change.
