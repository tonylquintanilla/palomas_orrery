## What the patch changes

- `gallery/feature_renderers.js`. The typed `KM_PER_AU` and obliquity
  (manifest section 5, lines 70 and 74) are deleted. `setFrameConstants()`
  takes both from `frame_constants` in `coverage_index.json`. Without
  `KM_PER_AU` nothing is drawn; without the frame's angle no pole is
  placed and rings and belts are drawn with no tilt. Each missing row is a
  warning.
- `interactive.html` calls it before drawing and shows its warnings with
  the room's notes. Earth's Python driver hands the served
  `pole_of_date` to the room untouched.
- `gallery/earth_geometry.js`. One pole for the whole room: when a pole
  of date is served, it replaces the orientation block's pole before
  anything is drawn, so the axis, equator, geostationary ring and belts
  share it. The axis hover prints the served tilt at its served count with
  its date, and no longer derives a tilt from the frame's angle. With no
  pole of date served, the frame's axis is drawn, the hover says so, and
  one warning names it.
- The test page `gallery/solar_system_earth_test2.html` and the seven
  smoke checks read the frame rows from the served cache, as the page
  does, and fail if a row is missing.
- `documentation/smoke_display_figures.js` grades the axis hover's tilt
  against the served block and holds the rest of that hover in the
  fixture with the tilt line replaced by a marker. The tilt and its date
  change with every cache build, so a fixture holding them would fail the
  next build for no fault. New fixture
  `fixture_hovers_L322d7_on_d892ed6e.json`; only that one entry differs
  from its predecessor, which is left in place unreferenced.

No cache build: the page reads what D6's build served.

## Found while building

- **The rings would have kept the old pole.** The first version moved
  only the axis to the pole of date. The belts and the geostationary ring
  are placed by the renderers from the served orientation block, and
  stayed on the frame's axis, 0.150 degree away. The Earth geometry smoke
  caught it (three plane checks failed). Fixed by giving the whole room
  one pole.
- **The hover budget check passes blind.** With the frame rows missing
  it measured 2 hovers instead of 96 and printed ALL CHECKS PASSED,
  because its only floor is "at least one hover". This patch makes it
  fail on missing frame rows; the weak floor itself is one ledger row.
- **The recorded Earth payload is aging.** `payload_earth_scene.json`
  (2026-09-08) predates the pole of date and still carries the magnetic
  tilt as 9.6, where the served cache has 9.4105. The checks that use it
  now overlay served data where it matters; the fixture itself is one
  ledger row.
- **Manifest section 5's tilt test, as built in D6.** It asked for the
  IAU 2006 formula within about 10 arcseconds and a monthly-wobble
  measurement in both copies' tests. D6 tests against ERFA's true
  obliquity within 1 arcsecond, which is tighter, and the wobble was
  measured once, by Tony's orrery live run (RUN_RECORD_L322_D4). Recorded
  here so the difference is visible, not silent.
