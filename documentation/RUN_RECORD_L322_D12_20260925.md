## 2. What the patch changes

- **New `exact_rows_report.py`.** Writes `EXACT_ROWS_PRINTED.md` in the
  orrery root and prints one line beginning "EXACT ROWS PRINTED:". The
  report names every exact row, every line that prints one with the code
  on that line, the rows printed only to a terminal, and the rows no
  display prints. It reads the gallery folder beside the orrery, as
  `data_inventory.py` does; if that folder is missing it says so at the
  top and in the summary line, and never presents the orrery half as the
  whole.
- **The gallery half is checked, not trusted.** A served value usually
  reaches its print line under another name, so a table in the tool,
  PRINTS, names the script, the function and a piece of the print line
  for each gallery pointer to an exact row. A pointer with no entry is
  reported as NOT FOLLOWED; an entry that matches no pointer or no print
  line is reported as BROKEN. A new exact row printed by the gallery
  therefore shows up first as NOT FOLLOWED.
- **`orrery_maintenance_run.py`.** A seventh generator, "Exact rows
  report", before "Document index", so `README.md` lists the report on
  the same run. A generator row may now carry a verdict hint, as a
  checker row does, so the report's summary line shows in the run itself
  and not only in the file.
- **`palomas_orrery_dashboard.py`.** "Exact Rows Report" beside the other
  generators, in alphabetical place.
