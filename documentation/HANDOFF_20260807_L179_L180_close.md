## Findings worth carrying

**The geometry was never wrong.** The shells have drawn at the correct radii
since August 2. Only the words drifted -- four restatements adrift from one
correct store, with every offline test passing throughout. L-181's thesis
demonstrated at one-tenth of Jupiter's size.

**The divergent class was enumerated, not assumed.** Tony asked the right
question mid-session: "why are we focusing on that one number. is it the only
divergent value in the codebase?" A 20-line check across all 157 Python files
and 35 store constants, looking for citations that name a constant and state
a value disagreeing with it, found exactly three sites -- two in L-179, one
in L-180. The class is closed and reads zero after the patch. That check is
the seed of L-189.

**The provenance scanner is blind to this class by construction.** It flags
UNCITED claims; every one of these was cited, which is why they survived
every clean run. A citation asserting a value the store does not hold passes
the check while making a false claim about provenance.

**`palomas_orrery.py` line 10295 was the hard case** -- a bare "126,000 AU"
in a scale tooltip with no import and no link to the store. Nothing mechanical
finds that; it is wrong only relative to a value in another file. If a similar
sweep is run later, remember the mechanical check has this blind spot.

**A test file nobody runs is not a check.** `test_constants_provenance.py`
asserted 126000 and had been false for five days. Tony, unprompted: "i never
run this file" -- which L-160 already recorded him saying on July 27. Its two
assertions are now correct and should be treated as the written spec for what
L-155's pinning engine absorbs into the scanner.
